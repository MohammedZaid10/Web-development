Static files :
https://expressjs.com/en/starter/static-files.html

make sure to always add this line in code for the files that you want to display to the user so that your backend code is not exposed to any user over your webpage, so in this case any file that is under the folder 'public' or 'files' will only be available for the user to see:
app.use(express.static('public'))
app.use(express.static('files'))
